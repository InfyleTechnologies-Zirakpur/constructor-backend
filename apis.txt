1. List Home Feed (Public Post Feed)
--------------------------------------------------------------------------------
Method: GET
Endpoint: /api/v1/posts
Authentication: Optional (Public / JWT Bearer)
Required Role: None (Public, job_seeker, company, admin)

Headers:
  Accept: application/json
  Authorization: Bearer <token> (Optional)

Path Parameters:
  None

Query Parameters:
  page (number, optional, default: 1): Page index (minimum: 1)
  limit (number, optional, default: 10): Page size (minimum: 1, maximum: 100)
  search (string, optional): Keyword search matching title, description, or tags
  tag (string, optional): Tag filter
  authorId (UUID, optional): Filter posts by author UUID (Honored ONLY for ADMIN; ignored for non-admin and anonymous requests)

Request Body:
  None

Authorization & Business Rules:
  - Returns only non-deleted posts (deletedAt IS NULL) with PUBLIC status/visibility.
  - Sorted newest first (createdAt DESC).
  - List items contain coverPhoto and truncatedDescription (up to 150 characters).
  - isMine dynamically evaluated: true if authenticated user is the post author, false otherwise.
  - isLiked dynamically evaluated: true if authenticated user has liked the post, false otherwise.
  - ADMIN responses include the author object (id, name, fullName, role, avatarUrl).
  - JOB_SEEKER, COMPANY, and ANONYMOUS responses DO NOT contain author or authorRole fields.

Endpoint: /api/v1/posts
Authentication: Required (JWT Bearer)
Required Role: admin, job_seeker, company

Headers:
  Authorization: Bearer <token>

  Accept: application/json

Path Parameters:

Query Parameters:

4. Update Post
--------------------------------------------------------------------------------
Method: PATCH
Endpoint: /api/v1/posts/:id
Authentication: Required (JWT Bearer)
Required Role: admin, job_seeker, company

Headers:
  Authorization: Bearer <token>
  Content-Type: application/json
  Accept: application/json

Path Parameters:
  id (UUID, required): The post UUID to update

Query Parameters:
  None

Request Body:
{
  "description": "Updated report: Quality inspector signed off and certified all beam welds.",
  "location": "Chandigarh IT Park, Site 4 (Block B)"
}

Authorization & Business Rules:
  - ADMIN can edit any post.
  - JOB_SEEKER and COMPANY can edit ONLY posts where post.authorId === requester.id.

  - Soft-deleted posts return 404 Not Found.

5. Delete Post (Soft Delete)
--------------------------------------------------------------------------------
Method: DELETE
Endpoint: /api/v1/posts/:id
Authentication: Required (JWT Bearer)
Required Role: admin, job_seeker, company

Headers:
  Authorization: Bearer <token>
  Accept: application/json

Path Parameters:
  id (UUID, required): The post UUID to delete

Query Parameters:
  None

Request Body:
  None

Authorization & Business Rules:
  - ADMIN can delete any post.
  - JOB_SEEKER and COMPANY can delete ONLY posts where post.authorId === requester.id.
  - If a user attempts to delete another user's post, 403 Forbidden is returned.
  - Soft-deletes the record (sets deletedAt timestamp).
  - Deleted posts are excluded from subsequent feeds, detail requests, and operations.

Successful Response (200 OK):
{
  "success": true,
  "message": "Success",
  "data": {
    "message": "Post deleted successfully"
  }
}

Error Responses:
  403 Forbidden:
  {
    "success": false,
    "message": "You are not allowed to delete this post"
  }
  404 Not Found:
  {
    "success": false,
    "message": "Post not found"
  }

6. Toggle Like Post
--------------------------------------------------------------------------------
Method: POST
Endpoint: /api/v1/posts/:id/like
Authentication: Required (JWT Bearer)
Required Role: job_seeker, company, admin

Headers:
  Authorization: Bearer <token>
  Accept: application/json

Path Parameters:
  id (UUID, required): The post UUID to like or unlike

Query Parameters:
  None

Request Body:
  None

Authorization & Business Rules:
  - Server-side like toggle.
  - If user has not liked the post: creates like record, atomically increments likesCount.
  - If user has already liked the post: deletes like record, atomically decrements likesCount.
  - Duplicate likes are prevented via database composite unique index (postId, userId).
  - Returns current user like state (isLiked) and updated post total likes count (likesCount).

Successful Response (200 OK - Liked):
{
  "success": true,
  "message": "Success",
  "data": {
    "isLiked": true,
    "likesCount": 13
  }
}

Successful Response (200 OK - Unliked):
{
  "success": true,
  "message": "Success",
  "data": {
    "isLiked": false,
    "likesCount": 12
  }
}

Error Responses:
  401 Unauthorized:
  {
    "success": false,
    "message": "Unauthorized"
  }
  404 Not Found:
  {
    "success": false,
    "message": "Post not found"
  }

7. Share Post
--------------------------------------------------------------------------------
Method: POST
Endpoint: /api/v1/posts/:id/share
Authentication: Optional (Public / JWT Bearer)
Required Role: None (Public, job_seeker, company, admin)

Headers:
  Accept: application/json
  Authorization: Bearer <token> (Optional)

Path Parameters:
  id (UUID, required): The post UUID to share

Query Parameters:
  None

Request Body:
  None

Authorization & Business Rules:
  - Public or authenticated users can share a post.
  - Atomically increments sharesCount using database atomic increment.
  - Returns updated sharesCount.
  - Soft-deleted or non-existent posts return 404 Not Found.

  "data": {
    "sharesCount": 3
  }
}

Required Role: job_seeker, company, admin

Headers:
  Authorization: Bearer <token>
  Content-Type: application/json
  Accept: application/json

Path Parameters:
  id (UUID, required): The post UUID to comment on

Query Parameters:
  None

Request Body:
{
