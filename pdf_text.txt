5. Core Business Logic
5.1 Daily project cost
Daily Project Cost = Labour Cost + Material Cost + Site Expenses + Other Configured Costs

The backend should calculate the consolidated daily cost from approved records. Avoid duplicating the formula in multiple
client apps; the API should remain the authoritative calculation layer.

5.2 Estimated daily profit
Estimated Daily Profit = Daily Project Value / Revenue - Daily Project Cost

The final financial formula and methodology must be approved by the Client before implementation. The SOW specifically
makes this approval a dependency.

11. File & Document Handling
AWS S3 is the file store for profile images, company/contractor/project/site documents, certificates, reports, receipts and
supporting attachments.
Client App -> Backend authorization -> secure upload flow -> S3
└-> PostgreSQL stores metadata/reference







Generate unique object keys; do not use user-provided filenames as the storage key.
Validate MIME type and file size.
Store owner, entity type, entity ID, object key, original filename, size and timestamps.
Use private S3 objects and controlled access URLs where appropriate.
Do not store large binary files directly in PostgreSQL.
